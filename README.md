# Сайт DAPI

Многостраничный сайт на чистом HTML, CSS и JS. Без фреймворков и внешних запросов,
шрифты и картинки лежат рядом.

Живая версия: https://permkvadrat59-star.github.io/dapi-site/

## Страницы

| Файл | Что это |
|------|---------|
| `index.html` | Главная |
| `studio.html` | Студия: сайты, автоматизации, ИИ и свои приложения (Рассыльщик, Вместе, Brother Team) |
| `cases.html` | Кейсы: СК-Инвест, Одиссей, Т.Парк |
| `team.html` | Команда |
| `vmeste.html` | Сообщество «Вместе» |

| `brother.html` | Скрытая страница. Попасть можно только четырьмя кликами по логотипу на главной: клики кладут пропуск в `sessionStorage`, без него страница сразу уводит на главную. Ярлыка в меню нет. Здесь «находится» приложение Brother Team |

## Как править

Готовые `*.html` в корне руками не трогаем, они собираются.

1. Текст и разметка страницы: `src/pages/<страница>.html`.
2. Общая рамка (левая колонка, подвал, `<head>`): `src/layout.html`.
3. Стили: `assets/css/site.css`. Поведение: `assets/js/site.js`.
4. Сборка: `python build.py`.

Сборка остановится, если в видимом тексте найдется буква ё, длинное тире или двоеточие.
Это правило текстов DAPI, оно проверяется автоматически.

## Три состояния одной системы

Это визуальный эксперимент v0.2. Брендбук он не меняет, решения оттуда не считаются утвержденными.

У сайта одно ядро и три состояния. Ядро не меняется: логотип, левая колонка, сетка и отступы,
углы 14 px и пилюли, тонкие линии, моноширинные подписи, лайм как единственный акцент.

| Состояние | Характер | Что меняется |
|-----------|----------|--------------|
| 01 Normal | спокойное, на молочном | обычная ширина букв, строчные заголовки, прямой кадр; лаймовые акценты уже есть |
| 02 DAPI | выразительное, на графите | широкий жирный капс, крупные буквы D A P I, системные подписи, скошенные кадры, пометки от руки |
| 03 Brother | скрытое | палитра и формы как у DAPI, буквы сразу показывают людей |

Normal и DAPI переключаются в левой колонке, хранятся в адресе (`#normal`, `#dapi`) и в `localStorage`.
Brother существует только на `brother.html` и включается четырьмя кликами по логотипу на главной.
Normal светлый, DAPI темный, но меняется не только фон: вместе с ним меняются ширина и регистр заголовков,
размер букв, форма кадров и набор подписей.
Фото во всех состояниях цветные. Кадр на первом экране листает команду сам каждые две секунды, клик показывает следующего.

Технически состояние это атрибут `data-mode` на `<html>`. Все отличия собраны в переменных
в начале `assets/css/site.css`, разметка у всех состояний одна. При переключении ключевые объекты
(заголовок, кадр с человеком, логотип в полосе, буквы) перетекают из старой формы в новую
через View Transitions; там, где браузер этого не умеет, состояние меняется сразу.

Собственный шрифт DAPI Display пока содержит шесть букв. Заголовки берут шрифт из переменной
`--display`: когда шрифт будет дорисован, достаточно поставить его туда первым.

### Откат эксперимента

Версия до эксперимента помечена тегом `dapi-before-visual-experiment`, эксперимент тегом
`dapi-visual-experiment-v0.2`. Чтобы вернуть сайт ровно к прежнему виду, не переписывая историю:

```
git rm -rq . && git checkout dapi-before-visual-experiment -- . && git commit -m "Откат эксперимента v0.2" && git push
```

## Экраны приложений в «Студии»

В списке приложений у каждой строки есть маленький экран `<figure class="peek">`.
На компьютере он появляется при наведении и идет за курсором в пределах строки,
на телефоне стоит под описанием.

Сейчас внутри заглушки. Чтобы поставить настоящий скриншот или видео, замените содержимое `figure`:

```html
<img class="peek-media" src="assets/img/apps/имя.jpg" alt="" loading="lazy">
<video class="peek-media" src="assets/video/имя.mp4" muted loop playsinline preload="none"></video>
```

Видео само запускается при наведении и останавливается, когда курсор уходит. Пропорции экрана 16:10.

## Оформление

- Цвета из брендбука v0.1: графит `#171717`, молочный `#F7F6F2`, лайм `#C7F36B`.
- Углы: карточки и картинки 14 px, кнопки и переключатели скруглены полностью.
  Скошенные кадры и лаймовые фигуры в состоянии DAPI повторяют наклон ноги буквы A из логотипа.
- Шрифты: DAPI Display (логотип и буквы D A P I), TikTok Sans (заголовки и текст),
  IBM Plex Mono (подписи), Neucha (пометки от руки).
- Лайм на светлом фоне работает только заливкой и подчеркиванием под графитовым текстом,
  цветом текста он становится только на графите.
- Иконки: Phosphor, лежат в `src/icons` и вставляются при сборке через `{{icon:имя}}`.
